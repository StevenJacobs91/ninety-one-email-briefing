Step Guide

Building your audience

Define who will receive this email. Upload a distribution list, select the regions and channels, and optionally link a Pardot list for automated send workflows.

  • Upload a clean CSV with at minimum an email column. First and last name improve personalisation.
  • Select all regions that apply — legal disclaimers will be applied per-region automatically.
  • Intermediary audiences require COBS-compliant footer language. This is applied automatically.
  • A Pardot List ID is only required for automated sends via the n8n workflow integration.
