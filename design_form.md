## Asset Type Customised Fields

### 🔴 Advertisement

**Unique fields to show:**

- Brief notes box (free form)
- Where will the ad appear? (Free form)
- Ad format (Print, digital — dropdown)
- Dimensions / sizes (free form)
- Target audience (Free form)
- QR code *(with message: Please add your QR code in SVG format in the attachments box. If you need to generate one, click here > Agent/preferred website to generate is linked.)*
- Copy (headline, body, disclaimers — free form)
- Attachments box
- Colour theme picker

---

### 🟠 Application Form

**Fields:**

- Brief notes box *(Please ensure all needs are described. We'd prefer changes to existing forms be marked-up on the PDFs and attached below please.)*
- Attachments box

---

### 🟡 Branded Item

**Fields:**

- Item type (pen, notebook, tote, etc — freeform)
- Is there a Supplier template to share with us? *(Yes I'll attach it / I'll ask for it / No — this can be a template that our design team populates for example to place a logo or design onto the item.)*
- Print method (engraving, screen print, embroidery — freeform)
- Branding desired (Logos, stripes, etc — freeform)
- Attachments box
- Colour theme picker
- Image selector/uploader box
- Brief notes *(Send us a message and describe everything that's not already captured. How can we help you?)*
